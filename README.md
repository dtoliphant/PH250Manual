# PH250Manual
The lab Manual for PH250 at BYU-I

## Chapter PDFs
Individual PDFs for each chapter are in [`Chapters/pdf/`](Chapters/pdf/), split from
`PH250_Lab_Manual_1.0.pdf` along its outline bookmarks. Each chapter file keeps its
section bookmarks and the printed page numbers of the full manual (part-divider pages
are skipped). After rebuilding the manual, regenerate them with:

    python split_chapters.py
